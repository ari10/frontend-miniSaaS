# Mini SaaS Frontend Application

## 📌 Overview
This project is a modern frontend application built using Vue.js to simulate a SaaS (Software as a Service) platform. It provides a user dashboard interface with authentication, role-based access, and API integration with a backend service.

The application demonstrates real-world SaaS architecture, including user management, authentication flow, and frontend-backend integration.

---

## 🚀 Features

### 🔐 Authentication System
- User login & registration
- JWT-based authentication
- Protected routes
- Session handling

### 👤 User Features
- User dashboard interface
- Profile management
- Subscription / access simulation
- API integration with backend

### 🛠️ Admin Features
- Role-based access control
- Admin dashboard (if implemented)
- User management (via backend API)

### 🎨 UI/UX
- Responsive layout
- Clean dashboard design
- Component-based architecture
- Modern frontend structure
